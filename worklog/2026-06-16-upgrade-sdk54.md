# 2026-06-16 — Upgrade to Expo SDK 54

## What changed

Upgraded the project from Expo SDK 52 → **SDK 54** and brought every package to
its latest SDK-54-compatible version.

| Package                  | Before    | After      |
| ------------------------ | --------- | ---------- |
| expo                     | ~52.0     | 54.0.35    |
| react                    | 18.3.1    | 19.1.0     |
| react-native             | 0.76.5    | 0.81.5     |
| expo-router              | ~4.0      | ~6.0.24    |
| react-native-reanimated  | ~3.16     | ~4.1.7     |
| react-native-worklets    | —         | 0.5.1 (new)|
| react-native-screens     | ~4.1      | ~4.16      |
| react-native-safe-area-context | 4.12 | ~5.6     |
| react-native-svg         | 15.8      | 15.12.1    |
| react-native-gesture-handler | ~2.20 | ~2.28     |
| @types/react             | ~18.3     | ~19.1.10   |
| typescript               | ~5.3      | ~5.9.2     |
| babel-preset-expo        | (hoisted) | ~54.0.10 (now explicit) |

## How

1. `npx expo install expo@^54.0.0` then `npx expo install --fix` to rewrite
   package.json to SDK 54 targets.
2. Bumped devDeps (`@types/react`, `typescript`) for React 19.
3. Clean reinstall (`rm -rf node_modules package-lock.json && npm install`) —
   the in-place update tripped a stale-peer ERESOLVE, a clean install resolved
   it.

## Breaking changes handled

- **Reanimated 4** moved its Babel plugin to `react-native-worklets/plugin`.
  Updated `babel.config.js` (still listed last) and added
  `react-native-worklets` as a direct dependency.
- **`babel-preset-expo`** is no longer transitively hoisted in SDK 54 — added it
  as a direct devDependency (Metro bundling failed with "Cannot find module
  'babel-preset-expo'" until then).

## Verification

- `npx expo-doctor` → **18/18 checks passed**.
- `npx tsc --noEmit` → clean (no type errors under React 19 types).
- `npx expo export --platform ios` → bundles successfully (1338 modules).

No application/screen code changes were required — the design system and all 16
screens compile and bundle unchanged on SDK 54.
